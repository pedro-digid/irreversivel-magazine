Custom theme for Irreversível Magazine.

== Description ==

A custom WordPress theme built for Irreversível Magazine (irreversivel.pt), featuring Tailwind CSS, Vite build system, GSAP animations, and Lenis smooth scroll.

== Installation ==

1. In your admin panel, go to Appearance > Themes and click the Add New button.
2. Click Upload Theme and Choose File, then select the theme's .zip file. Click Install Now.
3. Click Activate to use your new theme right away.
4. Run `npm install` and `npm run build` to compile assets.
